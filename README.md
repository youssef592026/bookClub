# موقع نادي «بين السطور»

موقع عربي (RTL) لنادي القراءة، React + Vite، بشكل ثلاثي الأبعاد، ويشتغل على كل الأجهزة.
متصل بقاعدة بيانات **Supabase** مع حسابات للمستخدمين وتسجيل دخول منفصل للأدمن، ويقدر الأدمن يغيّر أي صورة أو عنوان.

## التشغيل على جهازك
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # النسخة النهائية في مجلد dist
```
من غير إعداد Supabase الموقع بيشتغل في **وضع تجريبي** (البيانات والحسابات محفوظة محليًا في المتصفح، وكلمة مرور الأدمن `admin123`). لا تستخدم الوضع التجريبي لحسابات حقيقية أو على موقع منشور.

## ربط Supabase (مرة واحدة)

**1) أنشئ مستخدم الأدمن**
في لوحة Supabase: Authentication ثم Users ثم Add user ثم Create new user. اكتب إيميلك وكلمة مرور قوية، وفعّل **Auto Confirm User**.

**2) فعّل تسجيل المستخدمين**
Authentication ثم Sign In / Providers ثم Email، فعّل **Allow new users to sign up** وأوقف **Confirm email** لتسجيل الدخول فور إنشاء الحساب من غير رسالة تأكيد. حدّث Site URL وRedirect URLs لتشمل عنوان الموقع المنشور وعنوان التطوير المحلي.

**3) أنشئ الجداول**
افتح SQL Editor ثم New query، والصق محتوى ملف `supabase/schema.sql` كله، واضغط **Run**.
بعدها شغّل سطر واحد تاني (غيّر الإيميل لإيميلك):
```sql
insert into public.admins (email) values ('your-email@example.com') on conflict do nothing;
```
عند تحديث الموقع لهذه النسخة، أعد تشغيل `supabase/schema.sql` لتجهيز ملفات الحسابات وسياسات النقاط والتنبيهات.

**4) خد المفتاح العام**
Project Settings ثم API Keys، وانسخ **Publishable key** (أو anon public).
⚠️ لا تستخدم أبدًا `service_role` أو `secret` في الموقع، ولا تشاركه مع أحد.

**5) ملف `.env`**
انسخ `.env.example` باسم `.env` في نفس مجلد المشروع، وحط المفتاح:
```
VITE_SUPABASE_URL=https://eufehmfybefpfscknqbz.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=المفتاح-اللي-نسخته
```
ملف `.env` مش بيترفع على GitHub (موجود في `.gitignore`). شغّل `npm run dev` من جديد.

**6) ادخل كأدمن وارفع المحتوى التجريبي**
افتح `/#/admin` وادخل بالإيميل وكلمة المرور. من «النسخ الاحتياطي» اضغط **رفع المحتوى التجريبي لقاعدة البيانات**، وبعدها عدّل كل حاجة.

## لوحة التحكم
- **المحتوى والصور:** كل عناوين ونصوص وصور الصفحات (الرئيسية، الكتب، اللقاءات، المراجعات، الانضمام) والشعار وكتاب الهيرو.
- **الكتب / الفئات / اللقاءات / الأعضاء:** إضافة وتعديل وحذف مع **صورة لكل عنصر** (رفع من الجهاز أو رابط).
- **الأعضاء والنقاط:** إضافة وخصم نقاط مع السبب، وسجل لكل عضو.
- **حسابات المستخدمين:** البحث عن حساب مسجل وإضافة نقاطه أو خصمها مع السبب.
- **الاقتباسات:** مراجعة المشاركات قبل نشرها ومنح النقاط. **طلبات الانضمام:** متابعة الطلبات.
- **الإعدادات:** الاسم والروابط وقواعد النقاط وكلمة المرور.

الصور بتترفع لـ Supabase Storage (bucket اسمه `images`) وبتتصغّر تلقائيًا قبل الرفع.

## النشر على GitHub Pages
المتغيرات بتتدمج وقت البناء، فابنِ الموقع من جهازك (فيه `.env`):
```bash
npm install -D gh-pages
# في package.json أضف في scripts:  "predeploy": "npm run build",  "deploy": "gh-pages -d dist"
npm run deploy
```

## هيكل المشروع
```
supabase/schema.sql   الجداول والحماية (RLS) ومخزن الصور
src/lib/store.jsx     طبقة البيانات (Supabase أو وضع تجريبي) والأدمن
src/lib/images.js     رفع الصور
src/data/content.js   النصوص والصور الافتراضية للصفحات
src/data/seed.js      المحتوى التجريبي
src/components/       المكونات (كتاب 3D، إمالة، حقل الصور...)
src/pages/            صفحات الموقع، و pages/admin لوحة التحكم
public/images/        الصور التجريبية بستايل اللوجو
```
